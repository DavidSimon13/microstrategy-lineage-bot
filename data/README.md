# Datasets de Platform Analytics

Esta carpeta contiene los datasets utilizados por el robot de lineage de MicroStrategy.

## Proyectos

- Banca Comercial
- Sistemas y Operaciones
- CID / CIB
- Operaciones
- Datamart Auditoria
- IES2
- Pricing

## Seguridad

Estos archivos contienen metadata interna de MicroStrategy.

El repositorio debe mantenerse privado.

No almacenar:

- contraseñas
- tokens
- credenciales
- connection strings con passwords
- secretos de AWS
- secretos de MicroStrategy
